This repository contains a comprehensive collection of C++ programs based on the classic textbook "Object Oriented Programming with C++" by E. Balagurusamy. Each program demonstrates fundamental and advanced C++ concepts with clear, working examples.

## 🚀 Getting Started

### Prerequisites

- C++ compiler (GCC, Clang, MSVC, or MinGW)
- Basic understanding of C++ syntax
- Text editor or IDE (VS Code, Code::Blocks, etc.)

### Quick Start

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/cpp-balagurusamy-programs.git
   cd cpp-balagurusamy-programs
   ```

2. Compile any program:
   ```bash
   g++ "filename.cpp" -o output
   ./output
   ```

## 📁 Program Organization

The repository is organized by C++ concepts, with each `.cpp` file containing a complete, runnable program. File names are descriptive and indicate the concept being demonstrated.

### Naming Convention
- Files are named descriptively (e.g., `Classes and Objects - Basics.cpp`)
- Topics are grouped logically by concept
- Each file is self-contained with example usage

## 📚 Topics Covered

### 1. Basic C++ Concepts
- **Inline Functions** - Function inlining for performance
- **Reference Variables** - Memory aliases and pass-by-reference
- **Static Variables** - Persistent storage across function calls
- **External Variables** - Global scope and linkage
- **Scope Resolution Operator** - Accessing global members
- **Preprocessors** - Macros, includes, and conditional compilation

### 2. Arrays and Pointers
- **Pointer Basics** - Memory addresses and dereferencing
- **Pointer Arithmetic** - Navigating arrays with pointers
- **Pointers to Functions** - Function pointers and callbacks
- **Returning Pointers** - Dynamic memory and object lifetime
- **Arrays and Pointers** - Relationship between arrays and pointers

### 3. Strings and Character Handling
- **String Length** - Measuring string content
- **String Copy** - Duplicating string data
- **String Concatenation** - Joining strings together
- **String Comparison** - Lexicographic comparison
- **Character Input/Output** - Single character operations

### 4. Structures and Unions
- **Structure Basics** - Grouping related data
- **Arrays of Structures** - Collections of structured data
- **Structures with Pointers** - Dynamic structure allocation
- **Unions** - Memory-efficient data storage

### 5. Classes and Objects
- **Class Fundamentals** - Encapsulation basics
- **Member Functions** - Methods and data hiding
- **Arrays of Objects** - Object collections
- **Static Members** - Class-level data and functions
- **Friend Functions** - Accessing private members
- **Nested Classes** - Classes within classes

### 6. Constructors and Destructors
- **Default Constructor** - Automatic initialization
- **Parameterized Constructor** - Custom initialization
- **Copy Constructor** - Object duplication
- **Constructor Overloading** - Multiple initialization methods
- **Destructor** - Resource cleanup

### 7. Inheritance
- **Single Inheritance** - Basic class extension
- **Multiple Inheritance** - Multiple base classes
- **Multilevel Inheritance** - Chain of inheritance
- **Hierarchical Inheritance** - Tree-like inheritance
- **Virtual Base Classes** - Diamond problem solution
- **Abstract Classes** - Pure virtual functions

### 8. Operator Overloading
- **Unary Operators** - Single operand operations
- **Binary Operators** - Two operand operations
- **Arithmetic Operators** - Mathematical operations
- **Relational Operators** - Comparison operations
- **Assignment Operators** - Compound assignments
- **Stream Operators** - Input/output operations

### 9. Dynamic Memory Management
- **malloc/calloc** - C-style dynamic allocation
- **new/delete** - C++ dynamic allocation
- **Memory Leaks** - Common pitfalls
- **Smart Pointers** - Automatic memory management
